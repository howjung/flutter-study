# 12주차 중간발표 대본 (약 2분, 5분 이내)

공지 조건: 이미지 장표 3장 / 성명 먼저 / 1~5분 / 화면을 가리키며 설명
`[이름]`은 본인 이름으로 바꾼다. 소리 내어 두 번 읽어 보기.

## 장표 1 · 주제 (약 30초)
안녕하세요, 컴퓨터소프트웨어과 **[이름]**입니다.

제가 만든 앱은 **'약속 시각 기록'**이라는 가칭의 앱입니다.
취침이나 출근 시각을 정해 두고, 실제로 한 시각과 **얼마나 차이가 났는지를 분 단위 숫자로** 보여 줍니다.
화면을 보시면, 정한 시각 01:23, 실제 02:40을 고르고 기록을 누르면 **"77분 늦었어요"**라고 바로 나옵니다.

## 장표 2 · 문제 (약 40초)
이 앱을 만든 이유는 제 경험 때문입니다.

첫째, 밤에는 하루를 끝냈다는 보상심리로 폰을 계속 보다가 **2~3시가 넘어서** 자는 일이 많습니다.
둘째, 주말 알바는 17시 출근인데 16시 25분에 알람을 맞춰 놓고도 **2~3분 지각하는 일이 습관**이 되었습니다.

알람은 이미 있는데, **얼마나 어긋나는지는 기록이 없어서** 느낌으로만 알고 있었습니다.
다만 이것은 제 경험이고, 다른 사용자를 조사한 것은 아닙니다.

## 장표 3 · 핵심가치 (약 50초)
핵심 가치는 **느낌이 아니라 숫자로 확인하고, 기록으로 쌓인다**는 것입니다.

왼쪽 첫 화면에서는 정한 시각과 실제 시각, 두 개만 고릅니다.
가운데 화면에서는 기록을 누르면 차이가 한 문장으로 바로 나옵니다.
오른쪽 화면에서는 기록이 최신순으로 쌓여서, 4건을 한눈에 볼 수 있습니다.

지금 구현된 것은 여기까지이고, 앱을 다시 실행하면 기록은 사라집니다.
또 이 앱이 실제로 습관을 고치는지는 아직 검증하지 못했습니다.
이상입니다. 감사합니다.
