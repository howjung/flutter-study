# 12주차 중간발표 자료

공지(12주차) 기준: 이미지 장표 3장 + 대본. PPT 아님.

| 파일 | 내용 | 상태 |
|---|---|---|
| png/slide1-주제.png | 주제 + 실제 실행 화면 1개 | 완료 |
| png/slide2-문제.png | 문제 (밤 / 주말 알바) | 완료 |
| png/slide3-핵심가치.png | 핵심가치, 실제 화면 3개 | 완료 |
| script.md | 약 2분 대본 | 완료, `[이름]`만 바꾸면 됨 |

- 화면은 Chrome 실행 화면이고 입력값은 예시이다.
- slide*.html은 원본이다. 폰트(Noto Sans KR) 경로가 작업 PC 임시 폴더라 다시 렌더링할 때만 고친다.
- 12주차 공지에는 15주차 목표 요구가 없어서 장표에서 뺐다. (11주차 자료에는 있음)
