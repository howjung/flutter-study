# 12주차 중간발표 자료

공지 기준: 이미지 장표(PPT 아님) + 대본. 장표는 1장으로 줄였다.

| 파일 | 내용 |
|---|---|
| png/발표장표-한장.png | 주제 + 문제 + 핵심가치 + 앱 화면 3개 (1920x1080) |
| script.md | 말하는 글 대본 + 예상 질문 |
| slide.html | 장표 원본 (phone.js, phone.css, common.css 사용) |

- 장표의 앱 화면은 실제 앱의 문구·배치를 아이콘 없이 HTML로 다시 그린 것이다. 입력값은 예시이다.
- 12주차 공지에는 15주차 목표 요구가 없어 장표에서 뺐다. (11주차 자료에는 있음)
- slide.html 폰트 경로는 작업 PC 임시 폴더라 다시 렌더링할 때만 고친다.
