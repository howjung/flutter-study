# 첫 화면 구상과 확인 기록

> **상태: 11주차 변경(v12) 구현됨, 본인 환경 확인 전.** v11 화면에서는 `flutter analyze`·`flutter test`(13개) 통과, 아이폰 실기기(디버그)에서 AC1~AC6 통과. **v12 변경 후 `flutter analyze`·`flutter test`·화면 확인은 아직 미실행**, Chrome 환경도 미실행. "직접 확인" 표에는 실제로 확인한 것만 `통과`로 적고, 기대 결과를 실제 결과로 쓰지 않습니다. 근거 스크린샷은 `docs/evidence/`에 있습니다.
> 숫자(77분 등)는 설명용 예시입니다. `docs/PRD.md`와 같은 내용을 기준으로 합니다. **기준 PRD 버전: v12** (PRD가 바뀌면 이 문서도 맞추고 버전을 갱신)

## 화면 구상

- 앱 이름·주제: 약속 시각 기록 (가칭) — 정한 시각과 실제 시각의 차이를 남기고 확인
- 화면의 핵심 사용자 행동: 목표 시각과 실제 시각을 선택하고 기록해 차이를 확인
- 위에서 아래로 보여 줄 정보: 앱 이름 → 종류 선택 → 목표 시각 → 실제 시각 → 기록 버튼 → 결과 문구 → 기록 목록
- 입력·선택·버튼과 그 뒤의 반응: 종류 선택, 시각 선택기 2개, "기록" 버튼 → 결과 문구 표시, 목록에 한 건 추가
- 사용 전·빈 데이터·잘못된 입력: 기록 없음 안내 / 시각을 비운 채 기록하면 안내 표시, 목록 유지
- PRD 요구 번호와 화면 요소의 연결: 아래 스케치의 `[R번호]`
- 그림이나 화면 구상의 위치: 이 문서 (종이 스케치는 필요 시 별도 추가)

```
┌────────────────────────────────┐
│ 약속 시각 기록                 │
│                                │
│ 종류   ( 취침 )  ( 출근 )  [R1]│
│ 오늘 정한 시각은?    [ 01:23 ] │
│ 실제로 한 시각은?    [ 02:40 ] │
│               [ 기록 ]   [R2]  │
│ ※ 목표 시각과 실제 시각을      │
│   모두 입력해 주세요     [R4]  │
│                                │
│ 목표보다 77분 늦었어요   [R2]  │
│                                │
│ 이번 실행 중 기록 목록   [R3]  │
│ (앱을 다시 실행하면 사라져요)  │
│ 취침 · 목표 01:23 · 실제 02:40 │
│        · 77분 늦었어요         │
│ (없으면: 아직 기록이 없어요)   │
└────────────────────────────────┘
```

## 구현 계획과 실제 코드

- 프로젝트 경로·실행 장치: 경로 **미정**. 장치는 `flutter doctor -v` 결과(Flutter 3.47.2, macOS 15.8.2 Intel) 기준 **Chrome(웹)** 으로 실행할 계획. 1회차 doctor에서는 Xcode 설치 불완전이었으나 **2회차(Xcode 26.3 설치 후)에는 Xcode 인식됨**. CocoaPods 없음(경고), iOS 지원 플래그는 아직 꺼짐, 아이폰 미연결이라 아이폰 실기기는 후속(설정 전) (이 결과는 본인이 제공한 실행 출력이며 제가 직접 실행한 것이 아님)
- 새 프로젝트인지 기존 코드가 있는지: **미정**
- 생성·수정할 파일과 이유 (계획 확정, 본인 확인함):
  - `lib/main.dart`: 화면과 상태 (선택값, 결과 문구, 기록 목록)
  - `lib/time_gap.dart`: 차이(분) 계산 함수. 화면과 분리해 경계 조건을 확인하기 쉽게 함
  - `test/time_gap_test.dart`: 계산 함수 단위 테스트. 기본 생성 `test/widget_test.dart`(카운터 앱용)는 삭제
- 구현 세부 결정 (본인 확인함): 시각 표기 24시간제 강제 / 기록 후 선택값 유지 / 최신 기록이 맨 위 / 시각 표시는 `TimeOfDay.format` 대신 직접 `HH:mm` 생성
- 실제 변경 파일과 핵심 함수: 소스를 `promise_time/`에 작성함 (본인 프로젝트에 복사 후 확인 필요)
  - `lib/time_gap.dart`: `timeGapMinutes`, `gapMessage`, `formatHm`, `toMinutes`
  - `lib/main.dart`: `_HomePageState._record`(검증, 계산, 상태 갱신), `_pickTime`(24시간제 시각 선택기)
- **11주차 변경 (v12, A안)**:
  - `lib/gap_record.dart` (새로 만듦): `RecordKind` enum(취침/출근), `GapRecord`(모든 필드 final, 차이·문구는 저장하지 않고 계산), `RecordBook`(`add` 최신 앞 삽입, `count`, 읽기 전용 `items`)
  - `lib/main.dart`: 입력 검증은 화면이 하고 완성된 `GapRecord`만 `RecordBook`에 넘김. 목록 제목의 "N건"은 `recordBook.count`에서 바로 표시
  - `test/record_book_test.dart` (새로 만듦): 불변식 14개 (처음 0건, 추가 시 +1, 같은 기록 두 번 = 2건, 기존 기록 불변, 최신이 인덱스 0, 건수 = 목록 길이, 외부에서 목록 수정 불가)
  - 변경 없음: `lib/time_gap.dart`, 패키지, 저장, 알림, 화면 수
  - id 없음 (수정·삭제가 없어서, 넣는 시점에 검토)
- 예시 데이터·메모리·실제 저장 여부: 사용자 입력만, 기록은 메모리, 저장 없음
