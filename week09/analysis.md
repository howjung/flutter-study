### 선택·변경 이유 (본인 판단)

- 오답노트는 본인이 "마음에 들지 않고 대체될 것이 너무 많다"고 판단해 변경함.
- 선택한 주제는 직접 겪는 문제이고 숫자(분)로 확인할 수 있음.
- 같은 분야(취침 알림)를 고려하는 다른 학생이 있다는 것을 알게 되어, 알림보다 **시각 차이 기록**을 중심으로 잡음. (이름·상대 계획은 기록하지 않음. 이 항목은 쓰지 않아도 되는 선택 사항.)

- 목표 수면 시간 7~8시간, 폰은 아이폰

**가정 (미확인)**
- 알람 후 미룸 또는 준비 35분 부족이 지각 원인
- 알림과 기록이 어긋남을 줄임
- 취침과 알바 지각의 관계: **연결하지 않음** (알바가 17시라 근거 약함)

**미확인**: 학교 지각 여부 (이번 범위 제외), 다른 사용자 의견 (조사 안 함)

## 4. 기능 범위와 화면·데이터 (TODO4)

MoSCoW 분류와 이유는 `topic.md` 4절 참고. 분류 근거는 다음과 같음.

| 판단 | 이유 |
| --- | --- |
| 권장 취침 계산을 Could → Must로 올림 | 기상 알람이 요일별로 고정이라 매일 입력할 필요가 없어짐 |
| 기상 기록은 Should | 알람 후 미룸과 준비 부족을 구분할 수 있음 |
| 학교 지각 기록 제외 | 본인이 학교 지각을 말하지 않아 근거 없음 |
| 취침·지각 연결 분석 제외 | 인과 근거 약함 |
| 화면은 두 개 | 홈(입력·결과·목록)과 설정으로 충분 |

**미정으로 남긴 설계 문제**
- 알람이 늦으면 권장 취침도 늦어짐 (예: 월요일 12:00 알람이면 전날 밤 04~05시). 취침 시각 상한을 둘지 **결정 필요**
- 알바 날(16:25 기상) 권장 취침이 08~09시로 현실과 안 맞음. 알바 날은 수면 목표 대신 지각 기록 중심으로 할지 **결정 필요**
- 차이 계산 기준: 권장 구간(7~8시간)의 어느 쪽을 쓸지 **미정**
- 하루에 알람이 두 개(08:23, 08:25)인 날은 첫 번째를 기준으로 삼을 예정

## 5. 판단 기록 (선택·제외·이유)

상태가 "본인 확정"인 것만 본인이 직접 말하거나 요청한 내용이고, "제안"은 AI가 제안했고 본인이 아직 명시적으로 결정하지 않은 내용입니다.

| 항목 | 판단 | 이유 | 상태 |
| --- | --- | --- | --- |
| 오답노트 → 변경 | 채택 | 직접 겪은 불편이 아님 | 본인 확정 |
| 취침(A)과 알바 지각(B) 모두 다룸 | 채택 | 본인이 둘 다 있다고 함 | 본인 확정 |
| 보상심리를 문제에 반영 | 채택 | 본인 경험 | 본인 확정 |
| 수면 시간 맞추는 기능 | 채택 | 본인이 요청 | 본인 확정 |
| 학교 등교 시간 반영 | 부분 채택 (알람 시각만 반영) | 본인이 추가 요청, 학교 지각은 미확인 | 본인 확정 / 지각 기록은 제안 |
| 시각 차이 기록 중심 | 채택 | 알람이 있어도 지각 → 알림만으로는 부족 가능 | 제안 (본인 긍정 반응) |
| 수면-지각 인과 연결 | 거절 | 알바 17시 출근이라 근거 약함 | 제안 |
| 늦게 잔 이유 선택 | 보류 → Should | 동기 확인에 유용하나 필수는 아님 | 제안 |
| 기상 시각 기록 | Should | 미룸 확인 | 제안 |
| 취침 시각 상한 | Could, 보류 | 결정 필요 | 제안 |
| 인스타 감지·차단, 건강 앱, 로그인, 친구 비교 | 제외 | 권한·외부 의존·핵심 밖 | 제안 |
